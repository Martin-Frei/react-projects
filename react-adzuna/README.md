# React Adzuna Job Search

A React job search application powered by the [Adzuna API](https://developer.adzuna.com/). Search real job listings by title and location.

## Features

- Real-time job search via Adzuna API
- Filter by job title and location
- Responsive grid layout
- Salary display and direct apply links

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4

## Setup

1. Clone the repository
2. Install dependencies:
```bash
   npm install
```
3. Create a `.env` file in the project root:

VITE_ADZUNA_APP_ID=your_app_id
VITE_ADZUNA_APP_KEY=your_app_key

4. Get your free API credentials at [developer.adzuna.com](https://developer.adzuna.com/)
5. Start the dev server:
```bash
   npm run dev
```
